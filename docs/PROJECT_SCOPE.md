# Project Scope

## Purpose
Demonstrate how a Financial Crime Analyst can combine multiple risk signals to prioritize customers and investigations.

## Workflow
Customer profile → transaction exposure → AML/fraud/sanctions/KYC alerts → repeat-alert analysis → multi-risk analysis → counterparty intelligence → risk prioritization → escalation reporting.

## In scope
- Cross-domain financial crime risk
- Repeat-alert analysis
- Multi-risk customers
- Risk drivers
- Geographic exposure
- Common-counterparty analysis
- Customer risk prioritization
- SQL, Python, Tableau and Streamlit

## Out of scope
- Production sanctions matching
- ML fraud models
- Automated SAR filing
- Graph neural networks
- Production rule/model deployment

All data is synthetic.
